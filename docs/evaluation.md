# Evaluation

Production AI automation should be evaluated against explicit success criteria before release.

## Evaluation dimensions

- Task correctness and failure rate
- Robustness to malformed or adversarial inputs
- Tool-use authorization and boundary compliance
- Latency and resource consumption
- Regression behavior across model or prompt changes
- Human escalation quality for uncertain or high-impact cases

Store evaluation results with the exact configuration and artifact version so changes can be compared over time.
